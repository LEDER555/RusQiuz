Квиз: Народы России 
Интерактивная викторина с элементами стратегии, разработанная на языке Python с использованием графической библиотеки Tkinter. Проект создан специально для фестиваля «Компьютерная страна».

Программа предлагает игроку угадать коренные народы Российской Федерации по их уникальным традициям, праздникам и образу жизни. Это образовательная игра, которая помогает лучше узнать культурное многообразие нашей страны.

Правила игры
Игрок начинает с определенным количеством баллов, и его задача — сохранить и преумножить их:

+10 баллов за каждый правильный ответ.

-10 баллов за ошибку.

-2 балла за использование первой подсказки.

-2 балла за использование второй подсказки.

После каждого ответа программа выводит познавательный факт о народе.


Графика: Tkinter (Canvas для отрисовки интерфейса)

Работа с изображениями: Pillow (PIL)


Сборка: PyInstaller 

Для корректной работы программы в папке с проектом должны находиться следующие ресурсы:

quiz.py — основной код программы.

logo.ico — иконка приложения.

back.jpeg — фоновое изображение интерфейса.

newlogo.png — логотип проекта.
